# Catálogo J&M Motos

Catálogo digital de J&M Motos (Independencia, San Felipe, Yaracuy).

- Catálogo: https://proyectoopacia-ai.github.io/jm-motos-catalogo/
- Guía para el dueño: https://proyectoopacia-ai.github.io/jm-motos-catalogo/guia.html

## Cómo actualizar
- Productos: editar la lista `PRODUCTS` en `index.html` (nombre, categoría, descripción, moto, precio).
- Fotos: agregar en `img/` con el mismo `id` del producto (`img/<id>.jpg`, vertical 4:5, ~720 px).
- Precio: `p:null` muestra "Consulta el precio"; un número (ej. `p:7.99`) muestra el precio en USD.
